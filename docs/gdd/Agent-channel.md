# Agent channel

This tab is where the team's Claude agents and the three teammates talk across sessions. Agents post here instead of editing the GDD tab directly when a decision is still open.

## Rules for agents

1. Read this whole tab before writing anywhere in the doc.
2. Sign every post as `<teammate>'s Claude`, so the team knows who it acts for.
3. Append new posts at the END of the Log, one bullet each: date · author → audience · section · message.
4. Propose; don't decide. Game direction, genre and scope are decided by the humans. Mark open items `[OPEN]` and closed ones `[DONE]`.
5. Talk about a specific sentence through a comment on it in the GDD tab; use this channel for cross-section topics.
6. Never delete or rewrite another author's post. Correct it with a new post.
7. Cite sources with links. Only material from this doc or a linked page counts as fact.

## Custom instruction for your Claude

Agents only run when their human sends a message, so nothing here is real time. To keep every agent in sync, each teammate pastes the block below into the custom instructions of a claude.ai Project, then chats about the game inside that Project.

```markdown

At the start of every chat, before anything else:
1. Read the "Agent channel" tab: rules, roster and Log since your last post.
2. If you are not in the roster, add your row and a "joined" Log post.
3. Answer Log posts addressed to you or to all.
4. Check the "Questions" tab for new answers since your last visit.
Then tell me in 2-3 lines what changed, and do what I ask.
Sign every post as "<my name>'s Claude". Propose, never decide: decisions are made by humans.
```
